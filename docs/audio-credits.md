# 音频素材来源

本项目使用的音频资源均为 CC0 素材。

## 音效

来源：[Kenney](https://kenney.nl/)

许可证：CC0 / Public Domain

| 文件 | 用途 |
| :--- | :--- |
| `click.ogg` | 鼠标进入按钮时播放 |
| `fly.ogg` | 箭头成功飞出 |
| `miss.ogg` | 箭头被阻挡并消耗失误次数 |
| `win.ogg` | 本关通过或全部通关 |
| `fail.ogg` | 失误次数耗尽 |

## 背景音乐

许可证：CC0 / Public Domain

| 文件 | 用途 |
| :--- | :--- |
| `bgm.ogg` | 游戏过程中循环播放 |
